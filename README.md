# EnterpriseEasily_DB

SQL Server Database Project for the EnterpriseEasily Guitar Tab Search Platform.

## Overview

This project contains the database schema (tables, indexes, stored procedures, views, and deployment scripts) for the EnterpriseEasily application.

## Build

```bash
dotnet build
```

## Deploy

Build produces a `.dacpac` that can be deployed to SQL Server (LocalDB, Express, or full) using SqlPackage or Visual Studio.
